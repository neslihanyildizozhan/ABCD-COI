Neighborhood Opportunity, Cognitive Outcomes, and White Matter Microstructure: Insights from a Large Pediatric Study


Overview

This repository includes scripts for the data processing and analysis performed in the study titled “Neighborhood Opportunity, Cognitive Outcomes, and White Matter Microstructure: Insights from a Large Pediatric Study” 
The study uses data from the Adolescent Brain Cognitive Development (ABCD) study, release 5.1, accessible via NDA.

Data Preprocessing: Conducted in Google Colab
Statistical Analysis: Generalized Additive Models (GAM) performed in R version 4.3.1 using the 'mgcv' package

dMRI Harmonized Data: Details available in our previous study: https://www.nature.com/articles/s41597-024-03058-w

Multi-site diffusion MRI data Harmonization software:
https://github.com/pnlbwh/dMRIharmonization



Please execute the scripts in the following sequence:

	1.	Data Preprocessing
	2.	Cognition GAM Analysis
	3.	dMRI GAM Analysis
 	4.	Mediation Analysis
 	5.	Visualization
  
Researchers interested in accessing the data can visit the  https://nda.nih.gov/abcd/
